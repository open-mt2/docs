# Building

The client is packaged with Docker. The container handles the toolchain so the
host only needs Docker and Git.

## Requirements

- [Docker](https://docs.docker.com/get-docker/)
- Git

## Build workflow

The build is driven by Docker. Refer to the client repository readme for the
current commands and image names, since the packaging setup evolves with the
project.
