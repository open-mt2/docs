# Introduction

The OpenMT2 client is a modernized, refactored Metin2 client. It keeps the
original game content and UI while replacing the engine and platform layers
with open, cross-platform code.

## How it fits together

The **client** owns the game and UI, registers the game modules and uses the
**Python bridge** and the incoming **C# bridge**. It also links the **Neoeter
engine** directly for rendering, audio, models and world data. The **assets
packs** are content loaded through the engine.

The engine and bridges never include client headers, so the engine stays
reusable and the game layer stays replaceable.

## Incoming: C# modding

A C# bridge is planned as a shared, dev-first framework for server and client
mods. It will let a mod target both sides from one codebase.

## Platforms

The same sources build natively on Linux and cross-compile to Windows. Both
targets share the same window and input layer, renderer, Python runtime and
asset packaging.

Both targets compile, link and reach the login flow. The remaining gaps are
IME/CJK text input and the Windows login background scene.
