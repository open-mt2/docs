# Client

The OpenMT2 client is a modernized, refactored Metin2 client split into focused
packages. Each package owns a specific subsystem, so work can happen
independently while keeping the engine modular.

The client builds natively on Linux and cross-compiles to Windows from the same
Docker image. Both targets share the SDL2 window and input layer, the OpenGL
compatibility renderer, the Python 2.7 runtime and the asset packaging.

## Status

Linux and Windows both compile, link and reach the login flow. Windowing,
input, the GL renderer, headless audio, packaging and the boot smoke pass on
both targets. The remaining parity gaps are IME/CJK text input and the Windows
login background scene, both tracked in the devkit task sheet.
