# Other Projects

Smaller tools, libraries, and experiments that support the OpenMT2 ecosystem.

## Browse repositories

- [All OpenMT2 repositories](https://github.com/orgs/open-mt2/repositories)
- [Client packages](https://github.com/orgs/open-mt2/repositories?q=pkg_)
- [Documentation repository](https://github.com/open-mt2/docs)

## Adding a project

New projects get their own documentation instance under `projects/` and an entry
in the **Projects** menu in `docusaurus.config.ts`.
