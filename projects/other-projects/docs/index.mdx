# Other Projects

The repositories and tools that make up the OpenMT2 ecosystem.

## Repositories

- [client](https://github.com/open-mt2/client) — Cross-platform Metin2 game layer
- [devkit](https://github.com/open-mt2/devkit) — Client development kit
- [neoeter](https://github.com/open-mt2/neoeter) — OpenMT2 core engine
- [neoeter-python](https://github.com/open-mt2/neoeter-python) — CPython 2.7 host and bindings
- [speedtreebkr](https://github.com/open-mt2/speedtreebkr) — SpeedTree Geometry Baker

[All OpenMT2 repositories →](https://github.com/orgs/open-mt2/repositories)

## Adding a project

New projects get their own documentation instance under `projects/` and an entry
in the **Projects** menu in `docusaurus.config.ts`.
