# AI Usage

This started as a personnal "sandbox" that have no real goal but to test limits of the current state of Agentic AI for big codebase modifications.
It has no goal to become a stable, production project (for now). Usage of AI for code analysis and evolution is assumed, especially in the first big refactoring phases.

I like transparency, and be honest with my project, this project involve a lot of agentic AI processing to tackle the most difficult parts of it.
Manipulating a decades old legacy C++ codebase is a massive work and requires exceptionnal skills I don't really have at that time.

I'm a developper since almost 10 years, I've been working in a lot of projects, from low level to high level codebases, and improving this one has always
been one of my dream, and AI gave me the possibility to do so. But my final goal is to be able to maintain a part of it by myself.
