# Contributing

Thanks for taking the time to improve OpenMT2. Contributions of every size are
welcome, including typo fixes, clearer examples, and new guides.

## Improve the documentation

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm install`.
3. Run `npm start` and make your edits.
4. Check the production build with `npm run build`.
5. Open a pull request describing what changed and why.

## Writing guidelines

- Prefer short sentences and concrete examples.
- Use sentence case for headings.
- Put each page in the most relevant folder and give it a `sidebar_position`
  in the front matter.
- Use `_category_.json` to label and order folders.
- Run the build before pushing so broken links are caught early.

## Reporting issues

Open an issue on the [issue tracker](https://github.com/open-mt2/docs/issues) with:

- A short description of the problem.
- The page or file affected.
- What you expected to happen instead.

## Code of conduct

Be respectful and constructive. Assume good intent, keep discussions focused on
the project, and help newcomers get up to speed.
