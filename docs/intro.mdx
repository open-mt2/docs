# Introduction

Welcome to the **OpenMT2** documentation.

OpenMT2 is an open-source project focused on building a modern foundation for
Metin2 servers. This site collects the guides, references, and project notes
needed to work with the project.

:::note

These docs are actively being written. Some sections are still stubs, and
contributions are always welcome.

:::

## Start here

- **[Installation](./getting-started/installation)** — set up the documentation
  site and learn how the project is organized.
- **[Contributing](./contributing)** — report issues, suggest changes, and send
  documentation improvements.

## Projects

- **[Client](/client/)** — the refactored OpenMT2 client and its packages.
- **[Server](/server/)** — server-side services and configuration.
- **[Neoeter](/neoeter/)** — the Neoeter project.
