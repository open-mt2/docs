# Introduction

Welcome to the **OpenMT2** documentation.

OpenMT2 is an open-source set of projects focused on (re)building modern foundations for
Metin2 client and server. This site collects the documentations, references, and project notes
needed to work with any projects.

:::note

These docs are actively being written. Some sections are still stubs, and
contributions are always welcome.

:::

## Projects

- **[Client](/client/)**: Crossplatform modern Client.
- **[Server](/server/)**: Linux server.
- **[Neoeter](/neoeter/)**: Refactored eter packages project to a cleaner architecture.
- **[Other Projects](/other-projects/)**: tools, libraries...
